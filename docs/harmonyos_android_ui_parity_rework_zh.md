日期：2026-08-01

状态：**返工已完成；主应用、悬浮核对、详细面板与横屏分散 HUD 已重新验收**

## 1. 问题结论

用户在最终 Release 模拟器包中发现：首页、底部“对局”页和 HUD 与 Android 原应用明显不同，HUD 还可能无法显示。代码与双模拟器截图确认这不是平台自然差异，而是鸿蒙移植错误地进行了界面重设计和功能简化。

本记录保留原问题结论，同时以下文的返工结果替代当时错误的候选包。

## 3. 已确认差异

### 3.1 主应用主题

Android 使用固定深色 Material 主题：

- primary `#FFD54F`；
- onPrimary `#281E00`；
- secondary `#77D7C4`；
- background `#0E1420`；
- surface `#171F2E`；
- surfaceVariant `#263145`；
- onBackground/onSurface `#F1F4FF`。

鸿蒙当前错误地使用浅灰背景、白色卡片、绿色主按钮、紫色功能按钮和不同字号/留白。

### 3.2 首页与四个底部页面

- Android 首页没有鸿蒙添加的版本角标或“标准版/录屏功能版”副标题；
- Android 的标题、状态卡、按钮、卡片边框、底部导航、内容顺序和间距都属于产品界面，不能仅保留相同文字；
- 鸿蒙“对局”页增加了相册测试说明、始终可见的核对按钮、直接打开面板/HUD 按钮，并删除/改写了 Android 的状态卡、权限状态、结束按钮和三段说明；
- 鸿蒙录屏版新增了 Android 原版不存在的启动模式选择页及“三种模式”入口，属于未授权的新交互；
- 部分鸿蒙卡片测量宽度错误，按钮和文字发生横向裁切。

### 3.3 HUD

Android HUD 不是一个整体面板，而是按游戏画面安全区定位的多个独立 `TYPE_APPLICATION_OVERLAY` 部件：调整、再战、隐藏/显示、录像、单双打、识别我方、状态、速度顺序、耐久假设、双方场上槽位、四招伤害和详细入口。

Android 部件采用深色半透明背景、细边框和固定锚点，默认不遮挡中部游戏画面。横竖屏和用户调整后的部件位置/尺寸分别持久化。

鸿蒙当前只创建一个大型 `TYPE_FLOAT` 浅色窗口，把所有内容塞入同一矩形，因此外观、遮挡、触摸和隐藏语义都错误；没有当前对局时还会变成另一套占位页面。这也是“启动 HUD 没出现”或出现错误样式的直接根因之一。

## 4. 返工原则

1. 不重设计，不用“更符合鸿蒙风格”替代原界面；
2. 主应用保持 Android 的深色主题、文案、顺序、层级和显隐条件；
3. 标准版与录屏版共享界面完全一致，录屏版只保留 Android 原本存在的录像状态与控制；
4. HUD 按 Android `BattleDirectHudLayout.anchors`、默认尺寸、单/双打部件数量、透明色和交互逐项移植；
5. 没有有效对局时，HUD 仍按 Android 只显示工具栏及“请点击再战识别双方阵容”状态部件，不创建整页占位窗口；
6. 模拟器无法验证真实截图帧不影响界面等价验收，但不能把真实浮窗触摸/捕获隔离写成通过；
7. 重新构建、安装和截图对照前，旧鸿蒙包不再作为交付候选。

## 5. 返工验收

- 四个主页面分别与 Android 截图核对颜色、字号、卡片、顺序、按钮和底栏；
- 对局页在未启动、运行中、有/无修正草稿和标准/录屏两变体下逐项核对显隐；
- HUD 按 Android 锚点验证每一个独立部件的位置、尺寸、颜色、文字和可点击状态；
- 单打只显示双方各一个场上槽位，双打显示双方各两个；
- 隐藏 HUD 后只保留 Android 原本保留的控制，显示后恢复原位置；
- HUD 启动失败必须显示具体平台错误，不允许静默失败；
- 两变体 Debug/Release 构建、结构测试和模拟器截图通过后才重新交付。

## 6. 完成结果

- 主应用恢复 Android 固定深色主题、四个底部入口和原对局页三段操作说明，移除相册验收文案、直接面板入口与录屏专用启动页；
- 双方阵容识别完成后直接打开右侧 `TYPE_FLOAT` 核对面板，不再跳转到我误加的整页 12 槽核对界面；
- 普通详细面板改回深色半透明样式；HUD 拆成 Android 对应的独立悬浮部件，并按相同比例锚点布置；
- 横屏 `2772×1240` 下，双打显示 15 个窗口，单打显示 13 个窗口，隐藏后保留 6 个工具栏窗口；标准版与录屏功能版的面板、伤害、单双打、隐藏和恢复全部通过；
- 相册全屏静态图上的横屏视觉证据为 `.tmp/ui-parity/gallery-photo-hud-fullscreen.png`、`.tmp/ui-parity/gallery-photo-hud-single.png` 与 `.tmp/ui-parity/gallery-panel-dark.jpeg`；这些本地截图不提交 Git；
- 最终两个 Release 候选均完成干净编译和包校验，模拟器最后安装的是录屏功能版 Release 候选。真实捕获帧隔离、系统授权、真机浮窗触摸及录像仍遵守原真机验收边界。
