# 1.1.14 发布说明（Android 标准版）

日期：2026-11-19

版本 **1.1.14 (19)**，要求 Android 13+ / ARM64。

## 双打伤害修复

- 修复双打中龙爪等单体招式被错误套用范围伤害 ×0.75 的问题。
- 移除手动计算器与对局设置中的全局“范围招式修正”开关、保存状态及伤害请求覆盖字段，不再将所有招式强制当作范围技。
- 岩崩等范围招式继续依据招式数据与单打 / 双打格式自动计算范围减伤。
- 旧对局中的 `spread` 状态在读取后不再保存；旧请求中残留的 `isSpreadMove` / `isSpreadMoveOverride` 不再影响伤害。
- 保留原有天气、场地、墙、帮助、会心等条件与队伍数据。

## 切换回归

固定测试配置：50 级大嘴娃，实际物攻 150；对手红莲铠骑，HP 161 / 实际防御 120；不设置额外伤害加成。该配置只用于隔离计算行为，不表示一支合法配招队伍。

| 连续切换顺序 | 龙爪 | 岩崩 |
| --- | --- | --- |
| 双打 | 39–46 | 54–64 |
| 单打 | 39–46 | 72–86 |
| 再次双打 | 39–46 | 54–64 |

我方输出与我方承伤两个方向均覆盖；真实 Android 请求经过格式切换与状态保存 / 读取后，再交给打包引擎计算。

## 升级与已知事项

- 沿用原包名与生产签名，版本码由 18 升至 19；升级前可在设置中导出 JSON 备份。
- 仅维护 Android 标准版。GitHub Release 只上传 ARM64 APK，x86_64 Release 包仅保留本地。
- 本次未新增“实际只命中一个目标”的控制；范围技仍按现有内核的双打目标类型规则计算。
- 自动化与包级验证不等同于正式 APK 的手机覆盖安装或完整对战验收；本次未执行设备安装。
