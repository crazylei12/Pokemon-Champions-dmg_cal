# 1.1.9 发布说明（Android 标准版）

发布日期：2026-09-09

版本：`1.1.9 (14)` · 标签：`v1.1.9` · 源码分支：`main`

本次汇总 v1.1.8 后标准版的更新，只发布 Android ARM64 标准版。录屏版、HarmonyOS 和模拟器包不在本次维护及发布范围内。

## 下载与升级

- 文件：`Pokemon-Champions-Assistant-v1.1.9-arm64.apk`
- 系统：Android 13 或更高版本，64 位 ARM 手机或平板。
- 沿用原有应用 ID 和固定生产签名，版本码提升到 14。安装时选择覆盖升级；可先在设置中导出 JSON 备份。
- 旧录屏版用户安装此包会切换为标准版，本包不包含录屏功能。需要保留旧录屏功能的用户可继续使用历史版本。

## 本次更新

### 战斗 HUD 与计算操作

- 在 HUD 中切换双方场上宝可梦的形态，并按目标形态重新计算。
- 重新计算后保留当前编辑子页；长表单的顶部“返回/收起”附近提供重算入口，减少来回滚动。
- 纳入当前场上的持续特性效果，包括气场、灾祸、友情防守、队友增益、改换目标、先制招式阻止，以及天气、树果和特性压制。
- 威吓等入场或历史依赖效果仍需通过当前能力等级、HP 和场地状态表达；应用不会从当前在场者重复推演过去事件。

### 九月规则、Mega 与识别资源

- 更新 Champions 合法形态、招式池、道具和常用配招；不合法的上游预设招式不再作为当前合法候选推荐，用户确认的保存队伍保持独立。
- 超级阿勃梭鲁 Z、超级烈咬陆鲨 Z、超级路卡利欧 Z、超级具甲武者的特性分别更新为锋锐、漂浮、波导防护、硬爪。
- 流星突刺更新为 170 威力，并据当前游戏数据补充葱游兵的合法招式；劈开更新为 80 威力，吸取力量和祈愿的基础 PP 更新为 5。
- 更新 Master Data v18 映射：396 个官方形态、516 个本应用支持的招式、216 个特性、155 个道具及 25 个性格；保留旧编号含义。
- 中文词库补齐到 1292 条，修复“危险回避”等特性缺项；359 个形态均有普通与闪光图标特征。保留原有截图特征，完整私有图像语料尚未重新评估。
- 将构建工具 sharp 更新至 0.35.4，修复依赖审计发现的高危漏洞。

### 公开队伍码：入口新增，当前查询受限

新增十位公开队伍码导入入口，可核对配置后保存为整支我方队伍，或一次保存为六个对手配置。早期客户端的直连流程已实现；**游戏 1.2.0 当前在线查询在登录阶段返回 1001，尚未恢复可用**。v18 映射和离线协议测试通过不代表在线查询成功，请暂用两页截图识别或手动配置。

查询仅在用户主动操作时联网；截图识别和伤害计算仍在本地进行，会话凭据不写入队伍或备份。
