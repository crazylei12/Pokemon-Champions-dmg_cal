# 2026-09-10 标准版道具数据补全

仅修改标准版 `main`，按用户要求不处理录像版。

根因：固定的 Showdown Champions 快照仍将 11 件当前游戏道具标为 `Past`。计算器生成步骤过滤了它们，中文名称目录随之缺项，界面和 OCR 共用的 `itemCatalog` 也无法使用它们。此前 v18 队伍码映射仅收录应用目录已有道具，因而同样遗漏。

对照已有的客户端 1.2.0 / Master Data v18 `item.json`，完整表为 166 件；原映射只有 155 件。补齐突突头盔、气球、逃脱按钮、红牌、电气种子、青草种子、薄雾种子、精神种子、一般宝石、紧绑束带、大地膜。

`src/data/damage/champions-items.v18.json` 保存完整编号和规范英文名，并记录已校验源文件 SHA-256。`tools/champions-data.mjs` 在独立适配层按官方表开放道具，保留上游快照原样。计算器资源、中文词库及队伍码 v18 映射一起补全；旧版 v17 编号不变。

重建官方目录：`node tools/team-code-resolver/sync-champions-items.mjs <本地已校验的item.json>`。工具要求源文件与 v18 来源记录的哈希一致，拒绝缺失名称、重复编号/名称及既有编号含义改变。原始游戏数据仍保存在仓库外，不分发。

之后执行计算器准备、中文词库生成和 Android 资源生成。回归检查覆盖全部 166 件道具的官方目录、可用性、计算器注册、中文选择/OCR 名称、队伍码映射，并检查无关的进化奇石不会被开放。

沿用现有的构建补丁机制，补充气球的地面免疫和一般宝石的威力修正；不修改上游子模块源文件或第九世代。场地种子的能力等级由用户手动调整，计算器不能根据种子和场地自动加级。验证覆盖气球在重力/魔法空间下失效、四种种子不自动加级且不重复叠加手动能力等级，以及一般宝石的属性和魔法空间限制。

该补全不增加回合推进、反伤或自动换人模拟；突突头盔、红牌和逃脱按钮已可选择、识别与导入，不代表新增它们的完整触发流程。队伍码在线查询和实机 OCR 尚未重新验收。

验证结果：`npm test` 通过（27 项引擎/资源回归、7 项协议测试、TypeScript、版本及许可证检查）；Android 145 项单元测试强制重跑通过。Android 构建生成目录中的中文词库和队伍码映射与源文件完全一致，包含全部 166 件道具。未构建、发布或安装 APK。
