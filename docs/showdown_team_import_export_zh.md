# PS 队伍文本导入与导出

Android 标准版，2026-09-15。

## 使用

- 首页「导入 PS 队伍」粘贴 Showdown Import/Export 文本；支持 1–6 只，成员之间用空行分隔。选择能力分配模式，解析并预览中文名称、性格、特性、道具、招式、能力点与实际能力值，再命名保存为我的队伍。保存后立即刷新队伍库。
- 已保存的我的队伍卡片，以及游戏公开队伍码解析成功后的预览，各有「导出 PS 码」。弹窗可查看、选择并复制全部文本，不需要先保存公开队伍。
- PS 文本离线解析；不解析 PokePaste 网页链接、PS packed string 或游戏十位码。游戏码仍走原有独立入口。

## 能力点语义

依据 [Showdown 格式说明](https://github.com/smogon/pokemon-showdown/blob/master/sim/TEAMS.md) 与 [导入导出实现](https://github.com/smogon/pokemon-showdown/blob/master/sim/teams.ts)：Champions 模式的 EVs 存储能力点。因此默认导入及导出都使用 `EVs: 32 HP / 2 Atk / 32 SpD`，用于 PS Champions 队伍。兼容输入 SPs 和 Stat Points 标签，导出统一 EVs。

传统 EV 必须显式选择「传统 EV 换算」，单项按 `(EV + 4) / 8` 整数除法近似换算，输出仍是 Champions 能力点。导入验证单项 0–32、总和不超过 66；传统 EV 验证单项 0–252、总和不超过 510。非 31 IV 不保留并提示；等级统一 50 并对非 50 输入提示。缺少性格按 Serious 中性性格并提示。未写能力分配按零点。

昵称、异色、亲密度、球种、太晶和极巨等未使用字段会明确提示不保留；性别可保存并导出。未知字段、重复能力项、重复字段、重复招式、未知本地实体、超过六只均拒绝，不写入队伍库。

导出需要完整性格、能力点、特性、1–4 招式和 50 级；不猜测旧队伍缺失字段。导出重新计算能力值，若和完整的保存能力值不一致，要求先核对。零能力点也输出明确的 `EVs: 0 HP`。未记录的性别、昵称等不补造。

## 存储与验证

复用本地实体映射与 Champions 能力公式；保存使用独立 `ps-` ID、`importSource: SHOWDOWN` 和 `source.backend: showdown_text`，没有伪造游戏队伍码。原队伍不会覆盖。游戏码六人限制保持不变。

单元测试覆盖文本解析、六人队伍、昵称与性别、CRLF/BOM、EV 模式区分、非法输入、序列化重载及导出再导入。Android 编译和单元测试与设备界面验收分开报告；本轮未安装或发布 APK。
