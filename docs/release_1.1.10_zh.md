# 1.1.10 发布说明（Android 标准版）

日期：2026-09-10

仅发布 Android 标准版，版本 **1.1.10 (15)**，要求 Android 13+ / ARM64。录屏版和 HarmonyOS 已停止维护，历史分支与发布包保留。

## 变化

- 补齐 Master Data v18 的全部 166 件道具，新增此前遗漏的突突头盔、气球、逃脱按钮、红牌、四种场地种子、一般宝石、紧绑束带和大地膜；同步选择目录、中文 OCR 名称和离线队伍码映射。
- 修复气球的地面免疫及重力、魔法空间下的限制，补充一般宝石的威力修正。
- 场地种子的能力等级继续由用户手动调整，不根据场地自动加级，也不重复叠加已手动填写的等级。
- 移除标准版无效的录屏按钮，收紧顶部 HUD 按钮间距。旧布局升级时重新排列顶部四个操作按钮，保留其他自定义部件的位置。
- 修复协议测试在不同操作系统 gzip 头差异下的不一致。

## 升级与限制

沿用应用 ID 和生产签名，版本码由 14 提升至 15。升级前可在设置中导出 JSON 备份。旧录屏版安装本包后切换为标准功能集。

游戏 1.2.0 在线队伍码登录此前返回 1001，本轮未重新验证或修复在线查询，请继续使用截图识别或手动配置。道具补全不包含反伤、自动换人和完整回合触发模拟。本轮不包含真机覆盖升级、实机 OCR 或完整对战验收。
